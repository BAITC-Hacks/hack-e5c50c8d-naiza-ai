# «Аким на 5 часов»

Веб-симулятор для HackAlem AI: команда получает один условный бюджет и за пять решений меняет качество жизни в пяти районах. Движок показывает итоговый Score, слабый район, критические показатели, лаг внедрения, синергии и последствия выбранного набора.

Проект рассчитан на городского управленца, команду хакатона и жюри, которым нужно быстро пройти путь от исходных данных до объяснимого решения. Районы и показатели синтетические и не являются официальной статистикой.

## Что реализовано

- бюджет 100 и каталог из 14 городских и районных мер;
- выбор ровно пяти неповторяющихся мер с проверкой бюджета, направлений, районов и конфликтов;
- расчёт Score: 70% среднего уровня города, 30% самого слабого района и штраф за показатели ниже 40;
- лаг внедрения на горизонте восьми кварталов, синергии и вклад каждой меры;
- карта пяти районов с карточками и изображениями районов;
- страницы выбора, доклада, методики и сравнения сохранённых прогонов;
- «Тень другого решения»: соседние допустимые наборы с пересчитанными Score и полом;
- coaching и insights по выбранному сценарию без изменения основного движка расчёта;
- AI-доклад совета из четырёх ролей и секретаря через совместимый API xAI;
- проверенный запасной доклад по журналу, если ключ не задан или AI недоступен;
- локальная полка прогонов и API health-check для проверки запуска;
- Windows-запуск через `start-local.cmd` и файл `Akim.exe`.

## Пользовательский сценарий

1. Команда вводит название и открывает набор.
2. Выбирает пять мер, а для районной меры — район.
3. Интерфейс сразу показывает бюджет, карту и текущую проекцию города.
4. После заполнения пятёрки команда открывает доклад.
5. Движок считает Score, средний уровень, пол, критические провалы, синергии и лаг.
6. Доклад показывает сильные стороны, риски, последствия на восемь кварталов и соседние решения.
7. Команду можно сохранить на локальную полку и сравнить с другими прогонами.

## Технологии и архитектура

- TypeScript, React 19, Next.js 15 App Router;
- Tailwind CSS 4, Fraunces и Source Sans 3;
- Vitest и tsx для тестов и контрольного demo;
- Zod для проверки структурированных ответов совета;
- Leaflet для интерактивной карты;
- SDK `openai` только как клиент совместимого API xAI;
- модель совета по умолчанию `grok-4.7`, адрес `https://api.x.ai/v1`.

Основной поток данных:

```text
data/city.json
      ↓
validate() / simulate() / recommend()
      ↓
журнал Score, районов, критических показателей и синергий
      ├─ fallback-доклад без сети
      ├─ POST /api/analyze → совет и секретарь
      ├─ POST /api/runs → локальная полка
      ├─ GET /api/compare → сравнение сценариев
      └─ GET /api/health → проверка работоспособности
```

Балл считает только `simulate()` в `lib/engine`. AI объясняет уже готовый журнал и не придумывает числовые показатели. Это позволяет проверить расчёт без API-ключа и сети.

## Установка и запуск

Требуется Node.js LTS и Windows/macOS/Linux с PowerShell или обычным терминалом.

Node.js нужен не для самого расчёта как отдельной программы, а потому что интерфейс
собран на Next.js: браузеру нужен локальный сервер, который отдаёт страницы и API
маршруты (`/api/analyze`, `/api/runs`, `/api/health`). `localhost` — это адрес этого
сервера только на компьютере пользователя; данные не публикуются в интернет.

```powershell
git clone https://github.com/BAITC-Hacks/hack-e5c50c8d-naiza-ai.git
cd hack-e5c50c8d-naiza-ai
npm install
copy .env.example .env
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

На Windows можно открыть `start-local.cmd`: он проверит Node.js, установит зависимости при первом запуске, создаст `.env` из примера и откроет локальный сервер.

В проекте также есть `Akim.exe`. Это Windows-лаунчер для папки проекта: рядом с ним должны лежать `package.json` и `node_modules`, а Node.js LTS должен быть установлен в PATH. Лаунчер поднимает сервер на `http://localhost:4173`, показывает окно управления сервером и открывает браузер.

Для жюри и пользователей без установленного Node.js предназначен portable-релиз:
скачайте [akim-na-5-chasov-portable-win-x64.zip](https://github.com/BAITC-Hacks/hack-e5c50c8d-naiza-ai/releases/download/v1.0.0-hackalem/akim-na-5-chasov-portable-win-x64.zip),
распакуйте архив полностью и запустите `START-HERE.cmd`. Внутри уже есть нужный
Node.js runtime и зависимости; вручную устанавливать Node.js не требуется.

## Как проверить решение

Автоматическая проверка:

```powershell
npm run check
```

Команда запускает typecheck, Vitest и контрольные сценарии demo. Отдельно доступны:

```powershell
npm test
npm run demo
```

Ожидаемые контрольные значения:

- база без действий: Score `52.56`, средний `56.86`, пол `49.18`, район `nura`, два критических провала;
- пример методики: стоимость `95`, Score около `56.54`, пол `52.96`, провалов `0`, синергия `M10+M12`;
- дешёвый набор: Score `53.80`, средний `58.10`, пол `50.43`, резерв `39`;
- тесты проверяют бюджет, количество мер, повторы, направления, конфликты, лаг, синергии и недопустимые наборы.

После запуска сервера можно проверить:

```powershell
curl http://localhost:3000/api/health
```

Ответ содержит `ok`, версию данных и базовый Score. В браузере жюри достаточно открыть стартовую страницу, выбрать кнопку «Пример», перейти в доклад, открыть «Тень другого решения», сохранить прогон и открыть сравнение.

## Данные и интеграции

- `data/city.json` содержит пять условных районов, десять показателей, 14 мер, направления, цены, лаги, синергии, конфликты и вымышленные карточки жителей;
- все показатели направлены одинаково: 100 — лучший результат;
- карта использует локальные изображения из `public/districts`;
- Score, журнал и fallback-доклад работают без внешних сервисов;
- живой совет вызывается только сервером через xAI после успешного расчёта;
- локальные прогоны пишутся в `data/runs.json` и не должны публиковаться как персональные данные.

В репозитории нет вызовов `api.openai.com` и NVIDIA API. API-ключи нельзя добавлять в GitHub. Для живого совета ключ xAI задаётся только локально в `.env`:

```env
XAI_API_KEY=
XAI_MODEL=grok-4.7
```

## Ограничения

- данные синтетические и не заменяют официальную статистику;
- общей облачной полки между компьютерами и авторизации нет;
- без `XAI_API_KEY` живой совет недоступен, но расчёт и fallback-доклад продолжают работать;
- серверная полка прогонов рассчитана на локальную машину;
- публичной deployed-версии сейчас нет;
- одиночный `Akim.exe` — лаунчер папки проекта, а не полностью автономный portable runtime;
- portable-релиз запускает локальный Next.js-сервер, поэтому после запуска открывается браузер на `localhost`.
