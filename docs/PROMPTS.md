# Промпты сборки и досборки

Действующая модель — `data/city.json`, версия `astana-rules-v2`: бюджет 100, 5 районов, 10 показателей, 14 мер, Score = 0,7×средний + 0,3×пол − N_crit. База 52,56. Пример методики около 56,5. Числа 49,3 / 52,3 / 55,5 ниже относятся к старой формуле и для текущего кода не используются.

Два исполнителя, две задачи.

| | Grok | Codex, модель `gpt-5.6-luna` |
| --- | --- | --- |
| Сборка с пустой папки | Промпт A | Промпт B |
| Досборка текущего репозитория | Промпт C | Промпт D |

Сейчас код уже лежит в `akim-na-5-chasov`. Для этого дерева нужны промпты C и D. A и B нужны только если папку очистили и собирают заново.

Общие правила для всех четырёх — файл `AGENTS.md` в корне. Его вставлять не надо: оба агента читают его сами. В Codex Luna папка должна быть trusted, иначе проектный `.codex/config.toml` не включится. Надёжный запуск:

```powershell
cd C:\Users\admin\Desktop\Work\akim-na-5-chasov
codex -m gpt-5.6-luna
```

Проверка модели внутри сессии: `/status`. Должно быть `gpt-5.6-luna`. Усилие для досборки — `medium`. Если правка формулы или совета застряла, подними до `high` командой `/model`. Для сборки с нуля по `docs/PLAN.md` лучше `high`.

В PowerShell не используй `&&`. Команды подряд пиши через `;`.

## Промпт A. Grok, сборка с нуля

Вставлять в пустую папку, вместе с `docs/PLAN.md`.

```text
Ты собираешь «Аким на 5 часов» с пустой папки по docs/PLAN.md.
Иди промптами 0–7 из раздела 12 этого плана, по порядку.
После промпта 1 остановись и покажи вывод npm test и npm run demo.
Дальше не иди, пока периферия не выше центра минимум на 2 балла.
Балл считает только simulate(). Интерфейс по-русски.
Ключ XAI_API_KEY только на сервере, модель совета grok-4.7, baseURL https://api.x.ai/v1.
Не добавляй авторизацию, GIS и второй способ посчитать балл.
```

Дальше по одному вставляй промпты 1–7 из `docs/PLAN.md`. Каждый следующий — только после зелёных тестов предыдущего.

## Промпт B. Codex 5.6 Luna, сборка с нуля

Запуск: `codex -m gpt-5.6-luna` в пустой папке, рядом должен лежать `docs/PLAN.md`.

```text
Собери «Аким на 5 часов» по docs/PLAN.md, раздел 12, промпты 0–7 по порядку.
Работай в текущей папке. Стек: Next.js App Router, TypeScript, Tailwind, Vitest, Zod.

Жёсткие проверки после каждого промпта:
- npm test зелёный
- npm run demo печатает утро около 49.3, центр около 52.3, периферию около 55.5
- периферия выше центра минимум на 2
- пять самых дорогих пакетов по одному на час дают OverBudget

Если балл разошёлся с ориентиром сильнее чем на 0.5, чини порядок модификаторов в simulate(), не подгоняй тест.
Балл считает только simulate(). Модель совета не считает балл.
Интерфейс по-русски. Ключ только в .env, модель grok-4.7, baseURL https://api.x.ai/v1.
Не добавляй auth, GIS, Mapbox, базу данных.
В конце промпта 7 выполни npm test, npm run demo и npx tsc --noEmit. В ответе приведи три строки demo и список непроверенного.
```

## Промпт C. Grok, досборка текущего дерева

Вставлять в уже собранный `akim-na-5-chasov`. Движок, экраны, совет, тень, полка, печать и час 17:40 уже есть.

```text
Дособери «Аким на 5 часов». Код уже в репозитории. С нуля не собирай и формулу AQoLS не меняй, пока npm test зелёный.

Сначала прочитай AGENTS.md, README.md и lib/engine/canon.ts.
Потом пройди продукт как городской управленец и почини только то, что мешает защите.

Сценарий приёмки в браузере, ширина 1280 и 390:
1. Утро показывает балл 49,3, пол Нұра, кнопку «Открыть день» при непустом имени.
2. «Собрать центр» даёт живой балл 52,3 и цену 940. В журнале камеры Нұры не зачтены.
3. «Собрать периферию» даёт 55,5 и цену 970. Средний близок к центру, пол заметно выше.
4. Карточка, которая не влезает в остаток, несёт печать «не входит в бюджет» и не выбирается.
5. «Запечатать день» открывает доклад: сильные стороны, риски, последствия, цитату. Без XAI_API_KEY на экране пометка, что совет работает по журналу.
6. Клик по «Тени другого решения» возвращает на нужный час, и живой балл уже другой.
7. «Наступило 17:40» на периферии не даёт потратить 150: резерв 30.
8. Два прогона встают рядом на «Полке команд». Чужая version данных туда не смешивается.
9. «Собрать доклад» печатает одну страницу: команда, балл, пять решений, таблица районов, сильные стороны и риски.
10. На ширине 390 видны бюджет, балл и «Запечатать день».

Попутно поправь, если ещё торчит:
- в data/runs.json поле района-пола хранит id, а имя района показывается отдельно;
- сырые дельты шока в JSON не оставляют хвост вроде -0.5999999999999943, наружу один знак.

Не меняй data/city.json и веса, если тесты канонов зелёные.
Не коммить .env и data/runs.json.
В конце: npm test, npm run demo, и список того, что проверил в браузере. Если браузера нет, так и напиши.
```

## Как делить одну досборку между ними

Grok закрывает проход по экранам, русские формулировки и доклад. Codex Luna закрывает промпт D: поле района на полке, округление шока, типы и красные тесты. Оба читают один `AGENTS.md`, поэтому балл остаётся в `simulate()`.
